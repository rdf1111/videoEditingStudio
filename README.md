# videoEditingStudio (자막 스튜디오) — Windows downloads

Desktop app for Windows 10/11 that subtitles your own recordings, cuts them into short vertical clips, and posts a finished clip to your YouTube channel or TikTok account from the app.

- Download: see the **Releases** page of this repository (zip, unzip and run `SubtitleStudio.exe`).
